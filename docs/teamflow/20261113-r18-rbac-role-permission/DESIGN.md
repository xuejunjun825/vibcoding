## 0. 视觉与手感基线（look & feel，先读这节）

### 0.1 意图（一句话）

**安静的配置台**：一眼看清「这个角色能进哪些页、能点哪些按钮」，每次勾选都有即时、可撤回的回应；它必须像一棵可读的树，而不是一张要横向滚动的巨表。

本需求新增/重绘的界面只有 5 处：角色列表、三级授权页、用户分配抽屉、组织迁移/删除、只读总览。其余页面只换按钮判据，**视觉零变化**。

| 交互面 | 反馈 | 时长/曲线 |

| focus-visible | 2px 主色 outline；行内元素 `outline-offset: -2px`，按钮 `+2px` | 即时 |
| 按下 | 只换底色一档（主按钮 `#1A54BC`，次按钮 `#EAF1FE`）；**不做平移/缩放** | 80ms |

| 模块展开/折叠 | 箭头 rotate 160ms；子节点高度展开 160ms，**不逐条 stagger** | `--t-expand` |
| 保存按钮 | 无改动：disabled（EP 灰）+ 保存条文案「无改动」；保存中：16px loading，按钮**定宽 96px** 防抖 | — |

| toast | 右上、2s（错误 4s 可关闭）；成功带 ✓ | 240ms 淡入 |
| 保存条出现 | `translateY(8px) → 0` + fade | 160ms |
| 树内搜索命中 | 文案 `<mark>` 底色 `#FFF7E6`、文字不变色 | 即时 |
| 只读总览单元格 | hover 仅提亮该格 `#F7F9FC`，**无可点击暗示**（`cursor: default`） | 120ms |

### 0.4 动效与空态

- 只允许 `opacity` / `background` / `border-color` / `transform: translateY`。**禁止 scale、bounce、spring、粒子、渐变**。
- 抽屉：右滑入 16px + fade，240ms `cubic-bezier(.2,0,0,1)`；遮罩 fade 240ms。
- 骨架：角色表 5 行、树 6 行、动作表 6 行（`el-skeleton :rows` 自绘行高 44/32）；**不用整页 spinner**。
- 空态（必须区分三种，主操作不同）：
  - 无角色 → 「还没有自定义角色」+ 主按钮「新建角色」；
  - 树无数据 → 「没有可配置的页面」+「刷新」；
  - 筛选无结果 → `variant="filtered"`「没有匹配的页面或动作」+「清除搜索」；
  - 未选页面 → 右栏 compact 空态「从左侧选择一个页面」+ 一行解释「页面决定能不能进，动作决定能不能点」；
  - 仅看已授权且无授权 → 「该角色还没有任何授权」+「关闭『仅看已授权』」。
- 错误：`ErrorState` 保留 code/status + 重试；**409/400 一律不用 toast**，必须在保存条内联或弹窗内可操作。
- `prefers-reduced-motion: reduce` → 所有过渡 ≤1ms，抽屉去位移。

### 0.6 几何自洽（写死数值，防止“文本撑破容器”）

- 1440 视口：主区 = 1240（200 侧栏）；AdminLayout 左子导航 160 + 16 gap ⇒ **内容宽 1064**。
- 授权页：左树 **300** + 12 gap + 右面板 **752**；右面板表格贴边，头部内边距 12/16。
- 动作表列宽：**动作 236 / 端点 240 / 高危 48 / 档位 170 = 694 ≤ 750**（752 − 2 边框）；无横向滚动。
- 三档控件 170 = 3×52 + 2×1 + 2×6（内 padding 6）；52 ≥ 两个汉字（13px × 2 = 26）+ 左右 13。
- 动作行 52 = 码 16 + 名称 16 + 上下 padding 10×2；两行均 `ellipsis`，`title` 给全文。
- 树行：模块 40 / 页面 36；缩进 12 / 28；checkbox 16 + 8 gap；右侧计数区 40（`tabular-nums`）；label 剩余 **184 ≥ 176**（300 − 16 padding − 28 缩进 − 16 勾选 − 8 − 40 − 8），`ellipsis`。
- 角色表列宽：角色 240 / code 180 / 类型 72 / 状态 96 / 用户数 88 / 更新时间 170 / 操作 160 = **1006 ≤ 1062**。
- 抽屉 640：内边距 20 ⇒ 600；两列 292 + 16 + 292 = 600（用户分配的角色/组织并排也按此）。
- 保存按钮「保存并生效」5 字 ×13 = 65 + 左右 12×2 = 89 ≤ **96**。
- 高危 pill 40：「高危」22 + 左右 8×2 = 38 ≤ 40。
- 授权页在 ≥900 高时整页不滚：两栏 flex 填充剩余高度、各自 `overflow:auto`；`max-height` 兜底 `calc(100vh - 320px)`，最小 360。
- 黄色警示条文案上限 2 行；超过则折叠为「… 等 N 项」并可点击定位。

### 0.7 反模式（本产品出现即返工）

1. 把 36 页 × 72 动作平铺成一张大表；或 1440 下出现**整页**横向滚动（容器内滚动允许）。
2. 第三层左栏（已有全局侧栏 + admin 子导航 + 模块树），禁止再嵌一层树。
3. 档位只靠颜色区分（三档必须带「允许/受限/拒绝」文字）。
4. 给内置角色整页置灰（只锁 `PLATFORM_ADMIN` 的 `org:manage`/`tenant:manage` 两个码）。
5. 用 toast 承载 409/400 冲突（错误必须内联、可定位、可修复）。
6. 以为前端隐藏就是权限（服务端 403 才是防线；隐藏只为可读性）。
7. 全选/半选也弹确认框（廉价可逆操作不打断；只有高危授予与破坏性停用才确认）。
8. 保存后整页 reload 或要求重新登录才生效。
9. 卡片阴影、渐变、大色块、圆角 > 8（除 pill）、主按钮一屏两个。
10. 角色列表输入即搜（服务端数据，沿用既有「回车触发」约定）。

## 1. 设计目标与边界

**目标**：把「谁能进哪个页、谁能点哪个按钮」变成管理员可读、可改、可回退的界面，并让改动在**下一次请求**生效且不返 403 惊吓。

**本轮新增（相对旧界面）**：
- 新路由 `/admin/roles`（列表）与 `/admin/roles/:id/permissions`（三级授权）；
- `/admin/users` 的分配弹窗改为**右侧抽屉**并补齐角色/组织/业务域/厂商四要素；
- `/admin/orgs` 增删除、人员迁移；
- `/admin/permissions` 从「只读矩阵」改为「只读总览 + 指路」；
- 全局导航与按钮改读服务端三集合；角色停用横幅。

**明确不做**：动作条件表达式编辑、`DataScope` 范围可视化、高危动作审批流、暗色/移动端、多实例缓存广播、角色复制/模板市场。需求详情等业务页按钮**只替换判据**，布局与视觉零变化。

## 3. 页面线框

### 3.1 `/admin/roles` 角色列表

```
┌ 工具栏  [搜索角色名/编码  ↵]  [仅看启用 ○]            [ + 新建角色 ] ┐
├────────────────────────────────────────────────────────────────────┤
│ 角色名        编码            类型  状态   用户数  更新时间    操作   │
│ 平台管理员    PLATFORM_ADMIN  内置  启用    3     11-12 10:20  授权 编辑 │
│ 产品经理      PMO             内置  启用   12     11-11 09:03  授权 编辑 │
│ 外部审计员    AUDITOR          —     停用    0     11-12 14:02  授权 编辑 停用 │
└────────────────────────────────────────────────────────────────────┘
```

- 行操作：**授权**（文字按钮，主色，跳授权页）· 编辑 · 停用（红色，默认隐藏，hover 显示）。内置角色：停用 disabled + tooltip「内置角色不可停用（可改权限）」。
- 「类型」：内置 → 灰 pill「内置」；自定义 → `—`（无 pill）。
- 「用户数」点击 → `/admin/users?role=CODE`（复用用户页筛选）。
- 空/加载/错误见 §0.4；行数 ≤50 不分页，>50 前端分页 20/页（`el-pagination`，右下 8/12 padding）。
- 新建/编辑抽屉（640，`label-position="top"`）：
  - 角色名（必填，2–30，去首尾空格）；
  - 角色编码（必填，`^[a-z][a-z0-9_]{1,31}$`，mono，**创建后不可改**；编辑态 disabled + hint「编码是审计与授权的稳定标识」）；
  - 描述（textarea 3 行，≤200，右下角计数 `12·200`）；
  - 底部：取消 / 保存（96 定宽）。
- 停用确认（`ConfirmDialog` 480，`tone=danger`，必填原因）：
  - 影响 1–2 条：「该角色下 N 名用户将在下一次请求失去这些权限」「关联关系保留，重新启用即恢复」；
  - 若该角色含当前登录用户，追加一条：「**包括你自己**，可能使当前会话失去管理入口」；
  - 409 `ADMIN_LOCKOUT_RISK` → 弹窗内联红字（不用 toast），文案带原因与「保留 1 名启用管理员」提示。

### 3.2 `/admin/roles/:id/permissions` 三级授权（核心页）

```

├──────────────────────────────┬─────────────────────────────────────────┤
│ ▾ 设置              6/10    │  用户与角色  admin-users    [页面 允许▾]  │
│   ☑ 组织与租户              │  功能码 [org:manage 允许]  ▸ 高级              │
│   ◪ 用户与角色  admin-users │  ┌ 全选本页动作  已授 4/4  [搜索动作      ]┐ │
│   ☐ 权限总览    admin-…     │  │ 用户与角色/用户              端点   高危 档位 │ │
│ ▸ 需求域            3/4     │  │ user.action.create 新建用户   POST…   —  [允许|受限|拒绝] │
│ ▸ 交付域            5/8     │  │ user.action.disable 停用用户  PATCH… 高危 [允许|受限|拒绝] │
│ ▸ 协作              0/3     │  └──────────────────────────────────────────┘ │
│ ▸ 分析域            2/8     │  ⚠ 本页 1 个动作已授但页面未开放，不生效          │
│ ▸ 我的              3/3     │                                             │
├──────────────────────────────┴─────────────────────────────────────────┤
│ 3 项未保存          [重置]                              [ 保存并生效 ]   │ 56px sticky
└────────────────────────────────────────────────────────────────────────┘
```

**布局**：左树 300（模块 → 页面两级，页面可展开动作？**不展开动作**，动作只在右栏）· 右栏 = 页头（页面名 + 页面码 + 页面准入三档）→ 功能码区（可折叠）→ 动作表。

**左树**
- 模块行：checkbox（tri-state）+ 名称 + `已授页/总页`（`tabular-nums`，12px `#6B7280`）；模块可折叠，默认全展开。
- 页面行：checkbox（tri-state）+ 名称 + 页面码（mono 11px，`#86909C` 仅此处可作装饰）+ 半选琥珀点；选中态浅蓝底。
- 计数口径见 §6-I1；点击 checkbox = 批量勾选（§6-I2），点击行的其他位置 = 打开右侧面板，**两者不混淆**（checkbox 有独立 `@click.stop`）。
- 搜索：本地即时过滤（数据 ≤ 36 页/72 动作）；命中页面保留其模块；命中动作 → 页面保留并显示「N 个动作命中」。
- 「仅看已授权」：隐藏「页面 DENY 且本页无任何动作授权」的页面；模块若全隐则整组隐藏。

**右栏页头**
- 页面名（14/600）+ 页面码（mono 12）+ 页面准入三档（ALLOW/RESTRICTED/DENY，170）。
- 功能码 chips：每个绑定功能码一枚 chip（mono 12 + 档位小字），ALLOW 绿 / RESTRICTED 橙 / DENY 红；`title` 写「该功能码被 N 个页面共用」。
- 「高级」折叠区（默认收起）：本页绑定功能码的逐项三档编辑（影响所有共用页，展开时首行警示 12px「改动会影响共用此功能码的 N 个页面」）；`PLATFORM_ADMIN` 的 `org:manage`/`tenant:manage` 显示锁 + 禁改。
- 自动展开条件：页面非 DENY 且任一绑定功能码为 DENY（此时页面实际不可见）——展开并显示警示条。

**动作表**
- 列：动作（上行码 mono、下行中文名）/ 判定端点 / 高危 / 档位；表头 sticky。
- 端点列：mono 11、单行 ellipsis、`title` 全文；**视口 <1400 隐藏该列**（§8）。
- 行 hover 提亮；无行选中态；每行档位控件独立，改动即时反映到树计数与保存条。
- 表头上方工具行：`全选本页动作` checkbox（tri-state）+ `已授 x/y` + 右侧动作搜索框（本地）。

## 5. 状态与数据

- **取数**：授权页一次 `GET /admin/roles/{id}/permissions`（modules → pages → actions 树 + 当前 grant）；角色列表一次 `GET /admin/roles`；动作全集 `GET /admin/actions` 只在需要补齐名称/高危时用，主树已带则不请求。
- **本地状态**：`snapshot`（服务端原值）/ `draft`（编辑值）/ `dirty = diff(snapshot, draft)`；选中页面 `selectedPage` 落 URL query `?page=`，搜索 `?q=`、`?onlyGranted=1`（刷新/分享可复现）。
- **不做乐观提交**：所有改动停留本地，只有「保存并生效」一次 PUT 全量覆盖（对齐 AC-11）。
- **保存后**：`draft → snapshot`、刷新 `auth`、更新树计数；若响应带 `warnings`（动作有、页面 DENY）→ 以警示条保留，不用 toast 吞掉。
- **并发**：若响应含版本/`updatedAt` 冲突（409），弹窗「该角色权限刚被他人修改」[重新加载] [覆盖保存]；无版本字段时按 AC 以最后一次保存为准，并在保存前 200ms 重新拉一次快照做冲突探测（可选，TECHNICAL 定）。

## 6. 交互规则（与 AC 对齐，dev 按编号实现）

**I1 三态推导（唯一公式，`useRoleGrants.ts` 导出并单测）**

| 页面档位 | 本页动作 | 勾选框 |
|---|---|---|
| DENY | 全部 DENY | ☐ 未选 |
| DENY | 任一 ≠ DENY | ☐ + 琥珀点（动作不生效） |
| 非 DENY | 全部 ≠ DENY | ☑ 选中 |
| 非 DENY | 部分 ≠ DENY | ◪ 半选（`indeterminate`） |
| 非 DENY | 全部 DENY | ☑ 选中（页面开、无按钮） |
| 无动作页 | — | 页面非 DENY ⇒ ☑，否则 ☐ |

**I2 批量勾选（点击 checkbox 的唯一语义）**：☐/◪ → 页面置 ALLOW + 本页全部动作 ALLOW；☑ → 页面 DENY + 全部动作 DENY。模块 checkbox 对组内所有页面执行同一规则（全 ALLOW / 全 DENY）。半选→全选→取消的单测用例即此三态循环。

**I3 三层关系（必须在界面上说清）**：页面 DENY ⇒ 动作是否授权都**不生效**（保留配置，标琥珀）；功能码 DENY ⇒ 页面即使 ALLOW 也不出现在菜单（页头红 chip + 警示条）；动作 RESTRICTED ⇒ 通过但按 `DataScope` 收窄（沿用 r17，文案「仅在授权范围内」）。

**I4 保存差量**：payload 三类 subject 的完整集合（全量覆盖）+ 客户端计算的 `added/removed/changed` 仅用于计数与摘要；保存按钮只在 `dirty` 时可用；1 次保存 = 1 次 PUT = 1 条审计。

**I5 防锁死（409）**：不重试、不静默；弹窗列出被拒码（`org:manage`/`tenant:manage` 或「最后一名启用管理员」），并给「保留这两项」按钮 → 自动回滚这两项后重试。

**I6 高危二次确认**：保存时若「新增授予」了任一高危动作（`deploy.action.force_release`/`role.action.grant`/`user.action.disable`），先弹 480 确认：列出动作码 + 目标角色 + 影响；`requireAck`（我已知悉，仍要授予）；确认后才 PUT；取消则留在页面且不清空改动。

**I7 生效与刷新**：保存成功后 `await auth.refreshPermissions()`（带 `epoch`，旧响应丢弃）；侧栏菜单与按钮即时变化，**不整页 reload、不重登**；若改的是自己所属角色，保存成功文案追加「你的菜单与按钮已更新」。

**I8 搜索/过滤**：
- 查询按空白切词，所有词都命中才算命中（同时对页面名/页面码、动作名/动作码匹配）；
- 命中动作的页面在树上显示 `N 个动作命中`；右栏动作表保持全量但命中行文案高亮；
- 清除搜索恢复展开态与原选中页；URL 同步 `q`。

**I9 未保存拦截**：路由离开 + `beforeunload`；「放弃」后恢复 snapshot 再离开。

**I10 失效与越权**：角色 404 → 页内「角色不存在或已被删除」+ 返回列表；403 → 全局 403 或页内 `forbidden` 空态；角色被停用（本页打开时）→ 顶部琥珀条，不阻断继续配置与保存。
