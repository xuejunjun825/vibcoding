## 技术栈（20261108-r1 确立，按用户确认单修订）

- 运行时：本机 JDK **25.0.2**（Oracle OpenJDK arm64，Homebrew）。Boot 3.5.x 官方仅支持 JDK 17–24，故锁定 **Spring Boot 4.0.9 + Spring Cloud 2025.1.4**；不要引入 Boot 3.5 教程代码。
- 构建：**Maven 多模块**（父 `packaging=pom` + `api-gateway` + `demo-service`），不用 Gradle。
- 注册/配置中心：**Nacos 单机 standalone（服务端 3.3.0，客户端 nacos-client 3.1.1 via SCA 2025.1.0.0）**；发行包解压到仓库内 `.nacos/`（整个目录 gitignore），由 `scripts/nacos.sh` 下载/校验/启动/停止。不使用 Eureka、不使用 Spring Cloud Config Server。
- 网关：`spring-cloud-starter-gateway-server-webflux`（Cloud 2025.1 的正式 artefact 名），路由 `lb://demo-service`。
- 端口约定：**8080 网关 / 8081 示例服务 / 8848 Nacos HTTP / 8849 Nacos 控制台（3.x 默认 8080，必须改，否则与网关冲突）/ 9848 客户端 gRPC / 9849 服务端 gRPC**；允许环境变量覆盖，脚本默认值不变。
- 交付形态：**Makefile + bash 脚本**（`dev-up / dev-down / verify / lint / test / test-negative / clean`），**不用 docker-compose**（本机无 Docker）。
- **本产品线 P0 交付不含 Python 工程**（用户 20261108-r1 确认移除）：`make verify` 与负向用例由 bash 承担；README 可把本机 Python 3.14.3 作为事实记录，但不得作为验收依赖。

- 权限配置化（r18，取代 r2 的「矩阵常量即唯一判定」与「按钮复用功能码」）：授权唯一判定是 `PermissionService`，固定三序 **页面码非 DENY → 动作码 ALLOW/RESTRICTED/DENY → 既有 `DataScope` 收窄**；三层授权共用 `sys_role_permission(role_id, subject_type: FUNCTION|MENU|ACTION, subject_code, access)`，多角色**任一 DENY 即 DENY**，`RESTRICTED` 仍只收窄 `DataScope`；`PermissionMatrix` 退化为「**11 角色** × 60 功能码种子」来源（r24 起：第 11 个内置角色 `VENDOR_PM`；矩阵只声明「角色 × 功能码」，**角色 × 动作的 11 条 DENY 覆盖在 `RbacSeeder.actionAccessFor`**，不得塞进矩阵——塞进去会让「168 格 = preset + 覆盖」的门禁公式失效），运行时代码不得再直连 `accessOf/accessFor`；页面注册表 `sys_menu`（36 页，含新增 `admin-roles`）与动作注册表 `sys_action`（72 码，命名空间 `<模块>.action.<动作>`）均为**全局代码常量表**（`MenuRegistry`/`ActionRegistry`）落库，三向比对；写端点必须声明 `@RequiresAction` 或显式 `@PageOnly`（漏声明的由 s9/lint 拦截）；V12 种子按现有行为反推（600 功能码格 + 360 页面格 + 720 动作格 = 10 角色 × 168），r24 的第 11 角色由 V13 建角色行、168 行由启动预置自愈补齐（合计 **1848 = 11 × 168**），升级后可用能力必须与旧版逐格等价（既有 10 角色 1680 行逐格不变）；写操作提交后 `epoch++` 失效缓存，改完**下一次请求**即生效；防锁死 = 冻结 `PLATFORM_ADMIN` 的 `org:manage`/`tenant:manage` 且至少保留 1 个启用管理员（409 `ADMIN_LOCKOUT_RISK`），高危动作（`deploy.action.force_release`/`role.action.grant`/`user.action.disable`）默认仅管理员；门禁 `make rbac-verify`（s0–s9）。
