## 0. 观感与视觉意图（先读；本节是交互反馈与状态可见性的下限）

### 0.1 三张脸，一套刻度

同一产品里三个页面承担三种不同的「看」：

| 页面 | 隐喻 | 一句话 | 密度 | 装饰预算 |
|---|---|---|---|---|
| `/portal` 岗位工作台 | **值班台**（交接班纸） | 现在该做什么 | 最高：1200×744 内 5 区、24 个可点目标 | 近零：无插画、无渐变、无阴影堆叠，只靠留白与 12px 栅格分区 |
| `/dashboard` 数据看板 | **仪表台**（五块玻璃面板） | 整体怎么样 | 中：首屏 3 块，滚动看第 4/5 块 | 低：线宽 2px、网格 1px，数据比装饰亮一档 |
| `/reports` 自助报表 | **报表纸**（可带走的纸） | 把结论带走 | 高但有序：左抽屉 + 中间纸面 | 集中在一处：导出按钮与水印——因为导出物会离开系统 |

三条不可让渡的观感规则：

1. **数字长一个样**：三处同一指标的字号、精度、千分位、单位、颜色规则完全一致（同一个 `MetricValue`，格式取自后端 `AnalyticsMetrics` 的 `unit/precision`）。三处读数不齐，用户会先怀疑数据、再怀疑产品。
2. **颜色只表达语义，不表达装饰**：蓝=可操作/当前，绿=达成，黄=需要人判断，红=失败或越界，灰=不适用。没有「为了让页面好看」的彩色容器。
3. **状态永远看得见**：加载有骨架、降级有原因 + 重试、空有下一步、超出上限有修正建议。禁止静默留白、禁止用 `0` 冒充「无数据」、禁止四张「—」。

### 0.3 状态反馈（必须逐个实现，不能只做 hover）

| 状态 | 变化 | 时长 / 缓动 |
|---|---|---|
| hover 卡片 | 边框 `#C9D6EE` + `--shadow-card-hover`，内部不位移、不放大 | 120ms `--ease` |
| hover 表格行 | 底 `#F7F9FC` | 120ms |
| hover 行内操作 | `.row-actions` opacity 0 → 1（键盘 focus-within 同样出现） | 120ms；触屏/无 hover 设备常显 |
| active（按下） | 填充再深一档（主色 `#1A54BC`），**不做** scale/位移 | 80ms |
| focus-visible | `outline: 2px solid #2B6FE5; outline-offset: 2px`，不改布局 | 0ms（立即） |
| 禁用 | 去色而非降透明度：底 `#F2F3F5`、字 `#A9AEB8`、边框 `#E5E6EB`，`cursor: not-allowed`；`aria-disabled` + `title` 说明原因 | 0ms |
| 拖拽中 | 源 pill 透明度 .5；指针处 1px 虚线插入位；槽位高亮 | 跟手（无过渡） |
| 拖入非法槽（如维度拖进「值」） | 槽位边框 `#D9363E`、底 `#FDECEC`、光标 `not-allowed`，松手后 1.2s 内显示原因条 | 即时 |
| 数字更新（筛选变化） | 旧值→新值 120ms 交叉淡入；**禁止**滚动计数/弹跳 | 120ms |
| 保存成功 | 顶部 `.flash-ok` 1.6s，文案「已保存」；编辑器状态字变「已保存 · 14:02」 | 1.6s |
| 区块定位（从卡片跳看板） | 目标块 outline `2px #2B6FE5`（offset 2），1.6s 后淡出 | 240ms |

### 0.4 载荷 / 空 / 错 / 降级

| 场景 | 表现 |
|---|---|
| 首屏加载 | 结构先出现：工作台按 88/40/124/352 的固定几何铺骨架；看板按 280/220/200/160/360 铺骨架；编辑器表格 8 行 36 高。骨架用现有 `.skeleton`，**不**用 spinner 占位 |
| 二次查询（已有数据） | 旧表/旧图保留 + 顶部 2px `.loading-bar`；不闪骨架、不清空、不遮罩 |
| 导出中 | 按钮进入 loading + 文案「正在生成…」，其余界面可继续操作；>3s 追加「完成后自动下载」；**禁止**全屏遮罩 |
| 空（无数据） | `EmptyState` variant=empty：13/600 标题 + 12px 说明 + 一个主行动。看板不画空坐标轴，写「当前筛选无数据」+ [放宽时间范围] |
| 空（筛选后） | variant=filtered：「没有符合条件的结果」+ [清除筛选] |
| 区级失败 | 内联 `ErrorState`（compact）：人话 + 错误码（12px mono）+ [重试]；同一屏其余区正常 |
| 卡片批量失败 | 4 槽位收成一条 124 高的区级错误条「卡片刻度暂不可用 · 重试」，**不得**渲染 4 张「—」 |
| 待办单源失败 | 该 tile 的数字位置换成 12px「暂不可用 · 重试」，tile 高度/位置不变；其余两源正常 |
| 无权限访问某页 | 沿用现有 403 页；页内不出现「半个页面」 |
| 报表超上限（400） | 表格上方内联警示条：错误码 + 人话 + 修正建议（例：「分组 6,120 > 5,000，请减少一个列维度或缩小时间范围」），保留上一次成功结果并标灰「结果已过期」 |

| 等宽 | 12 / 400 / 18 mono | `#4E5969` | 需求编号、字段 key、错误码 |

规则：
- **≤12px 的灰一律 `#6B7280`**（对白 4.8:1）；`#86909C` 只允许 ≥14px。浅色底（`#EAF1FE`/`#FFF7E6`）上的 12px 文字改用 `#4E5969`（保证 4.5:1）。
- 数字列右对齐，单位 12px 紧贴数字后 4px；表格里单位只出现在表头（`平均周期（天）`），单元格不重复。
- 比率 1 位小数 + `%`；天数/人天 1 位小数 + `天`/`人天`；整数千分位；缺失一律 `—`（带 `title` 说明原因：无基期 / 无预估 / 无数据）。
- **前端不做除法**：比率、偏差、环比全部取后端字段；拿不到就显示 `—`。

### 0.7 本产品反面清单（评审时逐条对照）

1. 四张「—」卡片，或空模板只留白不给说明。
2. 数字滚动动画、弹跳、缩放；加载时整页 spinner。
3. 比率在前端用 `a/b` 算出来（第二套口径）。
4. 颜色是唯一信息通道（环比只变红绿、共享范围只变颜色、P90 与均值只靠深浅）。
5. 两个「工作台」都叫工作台，菜单无法区分。
6. 筛选不同步 URL：刷新丢筛选、无法把「同一口径」发给同事。
7. 宽交叉表无冻结首列/表头不吸顶，横向滚动后行标签丢失。
8. 空结果显示空坐标轴；`0` 与「无数据」混用。
9. 导出按钮触发全屏遮罩；水印只在滚动到底才看得到；CSV 首行注释被当成表头。
10. 拖拽是唯一操作路径（无键盘/无「添加到」菜单）。
11. 共享后打开看到「分享者的行」；PUBLIC 被理解成「全量公开」。
12. 卡片点击跳到无筛选的裸看板，上下文丢失。

### 1.2 三页的数据关系

```
/portal（值班台）──点卡片/待办──▶ /dashboard?domainId&vendorId&from&to&metric
        │                                   │
        │                              「在报表中打开」

   列表页（带筛选）                    /reports/new?dataset&rows&measures&filters
                                            │ 保存
                                            ▼
                                      /reports/:id
```

- 三页共享**同一筛选 query schema**：`domainId` `vendorId` `from` `to` `preset`（`7d|30d|90d|custom`）。默认：本域 + 近 30 天（PRD §5.1）。

- 报表「共享」只共享**定义**：打开者看到的行按其自身 Scope 计算。此语义必须在共享对话框、列表段说明、PUBLIC pill 三处同时可见（见 §4.4、§6.4）。

### 4.4 工具条与画布

**工具条（44）**
- 图表类型分段：表格 / 柱状 / 堆叠柱 / 折线 / 饼。不可用项置灰 + `title` 原因：
  - 柱状：需 ≥1 行维。
  - 堆叠柱：需 ≥1 行维且（列维存在或 ≥2 度量）。
  - 折线：行维必须含时间字段（创建周/创建月/计划完成月/发起月/月份），否则「折线需要时间维度」。
  - 饼：恰好 1 行维 + 1 度量 + 0 列维 + ≤8 组；超 8 组提示「饼图最多 8 类」并提供 [改为柱状] 一键切换；当前是饼且数据变 >8 组时自动切柱状 + 12px 提示「已切换为柱状（分类 12 > 8）」。
- 右侧：`128 组`（12px；截断时 `已截断至 5,000` + 警告色）、缓存 chip（`缓存命中` 灰 / `实时计算` 蓝，`title`「300 秒内复用同参数结果」）、[刷新] 图标按钮。
- 筛选/字段变化后 300ms 防抖；在途请求 `AbortController` 取消；期间保留旧结果 + `.loading-bar`。

**交叉表（Canvas）**
- 结构：行头列（冻结，260）+ 值列（≥96，可多列）+ 小计列（120，固定在滚动区最右，不随横向滚动）+ 总计行（最后一行，`#FAFBFC`，600）。

- 单元格：13px tabular，右对齐；`null → —`（`#A9AEB8`，`title` 原因）；`0 → 0`；超长数字不换行；单元格 hover 显示行列坐标 tooltip（「D1 · 10 月 · 需求数 = 138」）。

- 横向滚动条常驻（`overflow-x: auto`，滚动条 10px）；行头阴影 `2px 0 4px rgba(0,0,0,.04)` 表示有被遮内容。

- 图表的表格替代：图表模式下工具条右侧保留「表格」切换；图表容器 `role="img"` + `aria-label`（前 5 项 + 总计）。

**图表（BaseChart）**

## 5. 交互与动效

### 5.1 筛选是唯一真相

- 状态**只**存 URL query（`domainId/vendorId/from/to/preset`，报表编辑另有 `dataset/rows/columns/measures/filters/chart`）；组件内不保留第二份。
- 变更 → `router.replace`（不污染历史）→ 300ms 内合并请求；「重置」清空到默认（本域 + 近 30 天）。
- 刷新/前进后退必须还原；从卡片/看板跳转带入的 `metric`/块焦点只做一次性 outline，不写入持久状态。
- 非法 query（未知字段、超范围日期）：前端丢弃该键并用默认值，同时 12px 提示「部分筛选已重置」；不白屏。

### 5.2 拖拽

- 指针拖拽（Pointer Events），阈值 4px 才进入拖拽态；拖起后源 pill 透明度 .5，跟随元素为 pill 的 1:1 副本（带 `--shadow-pop`）。
- 插入位：目标槽内显示 1px 主色竖线；槽位整体高亮 `#EAF1FE`。
- 松手即提交（走 300ms 防抖）；非法落点回弹 120ms 并提示原因。
- 键盘/触屏：字段行菜单 + pill 的「移到…」菜单，功能与拖拽等价。

### 5.3 时序与反馈

| 动作 | 反馈 | 时序 |
|---|---|---|
| 切换筛选 | 旧数据保留 + 顶部进度条；完成后数字 120ms 交叉淡入 + `aria-live` 播报「已更新 5 个区块，数据截至 14:02」 | 请求返回即止 |
| 拖动字段 | 槽位高亮跟手；松手后槽位内先出现 pill，再发请求 | 0ms / 300ms |
| 切换图表类型 | 表格↔图 160ms 交叉淡入（不同时渲染两份 DOM 之外的内容） | 160ms |
| 打开共享/设为卡片 | Dialog 160ms opacity + 8px 上移；关闭 120ms | 160/120ms |
| 打开配置 Drawer | 240ms 右滑入 | 240ms |
| 保存 | 按钮 loading 600ms 内完成不显示 loading 文案，超 600ms 显示「保存中…」 | — |
| 导出 | 按钮 loading + 「正在生成…」；完成 toast + 浏览器下载 | >3s 追加说明 |
| 删除行 | 120ms 高度收起 + 淡出，下方行 120ms 上移 | 240ms 总 |

页面级动效（路由切换）沿用 AppShell 的 120ms opacity/translateY(2px)；**不新增**页面级转场。

### 5.4 深链

- 工作台卡片 → `/dashboard?domainId=D1&from=…&to=…&vendorId=&metric=req.total`；块按 `metric` 滚动到对应块并 outline 1.6s。
- 看板块 → `/reports/new?dataset=…&rows=…&columns=…&measures=…&filters=…`（JSON 紧凑编码，长度 <2KB；超长则提示「参数过长，已带入前 3 项」）。
- 报表共享链接：`/reports/:id` 对无权限者一律 404 页（不区分「不存在」与「无权」）。

## 7. 无障碍

1. **键盘全通路**：所有拖拽动作有菜单等价物；字段行 Enter 打开「添加到…」；pill `⋯` 菜单；槽位 `Tab` 顺序 = 行→列→值→筛选；Dialog/Drawer 焦点陷阱 + Esc 关闭 + 关闭后焦点回到触发按钮。
2. **焦点可见**：统一 2px 主色 outline + 2px offset；深色底（主按钮）上用白色内描边补一层，保证可见。
3. **表格语义**：`<table>` + `<caption class="sr-only">`（如「需求按域与月分布，含小计与总计」）；`th scope="col|row"`；冻结列用 `position: sticky` 不破坏语义。
4. **图表等价**：`role="img"` + `aria-label`（前 5 项数值 + 总计）；图表模式始终可切回表格；合并「其他」时 aria-label 说明。
5. **动态播报**：筛选/刷新完成、字段添加/移除、保存/复制/删除、导出开始与完成，用 `aria-live="polite"` 单行播报（不播报每次键盘移动）。
6. **颜色非唯一**：环比带 ▲/▼ 与文字；P90 有文字微标；共享范围有文字；周期分段有段名与数值。
7. **命中区**：所有图标按钮 ≥28×28，pill 的 × 命中区 24×24（视觉 16）。
8. **动效**：`prefers-reduced-motion: reduce` 时所有过渡 ≤1ms、图表 `animation:false`；不自动播放、不循环动画。
9. **缩放**：200% 文本缩放不截断关键数字（卡片允许换行增高，最小高度 124 改为 `min-height`）。
10. **错误可读**：错误码用 mono 12px 附在人话之后，不把 `REPORT_TOO_MANY_GROUPS` 单独甩给用户。

## 9. 设计决策与待确认

**已定（本设计的选择及理由）**

| # | 决策 | 理由 |
|---|---|---|
| D1 | 不改 `MetricCard`，新增 `AnalyticsCard` | 新卡有「环比 + 个人报表卡」两种形态，改公共组件会波及 M6 已验收页面 |
| D2 | 三页共用 `MetricValue` + 后端精度 | 「三处逐位一致」只能靠单一格式实现保证，不能靠三处各自 format |
| D3 | 筛选只存 URL，`replace` 更新 | 刷新/分享/回退都还原；避免每次筛选塞满历史 |
| D4 | 图表用已装 ECharts 6，封装 `BaseChart` | 交叉表转置、堆叠、饼需要真实图表库；现有 CSS 自绘只适合条形 |
| D5 | mgmt 待办区渲染只读条而非隐藏 | 同时满足「五区齐全」（AC-2）与「不展示三源」（PRD §6.2） |
| D6 | 个人卡先占槽、模板卡补齐、总数 ≤4 | 「个人 > 模板、不叠加」的可实现解释；避免 4+4 溢出 |
| D7 | 卡片批量失败收成一条区级错误条 | 直接消灭反面目标「四张—」，也不假装单卡成功 |
| D8 | 报表不做自动保存 | 聚合查询可能很贵，静默保存会制造垃圾定义；用脏数据守卫 + Cmd/Ctrl+S 降低丢失 |
| D9 | 饼图 >8 类自动切柱状并提示 | PRD 要求禁用饼；自动切走比让用户面对禁用按钮更少一步 |
| D10 | CSV 在菜单内被明确标注「仅供系统对接」 | 水印只在 XLSX；把「对外提交」的默认路径做成唯一推荐路径 |
| D11 | 交叉表「小计/总计」不参与排序交互 | 本轮无排序需求，排序会让总计语义含混 |
| D12 | 报表列表不做分页器，20 行后「查看全部」 | 报表数量级小，分页器增加噪声 |

**待确认（沿用 PRD §9 的 6 项，设计侧给默认）**

1. MGMT 的 `mgr1` 种子账号：默认加（否则 mgmt 模板无法演示）。
2. 「设为卡片」超 4 张：默认拒绝并列出当前 4 张（D7/§4.5），不替换。
3. 宽交叉表：默认冻结首列 + 表头吸顶 + 横向滚动（§4.4），不提供「列折叠」。
4. PUBLIC 是否放开：默认放开，但三处明示「只共享定义」。
5. 管理员是否可新增卡片（非模板内指标）：默认不支持（只做显隐），避免扩大 `PORTAL_CONFIG` 契约。
6. 报表是否允许跨数据集：默认不允许（PRD 明确 `REPORT_DATASET_MISMATCH`）。

**给技术方案的 5 条界面约束（不是建议）**

1. 三页所有指标格式化走 `MetricValue`；前端源码不出现 `a / b` 形式的指标比率。
2. 工作台一次性返回五区数据 + `todoSources[]` 每源状态 + `todoMode`；前端按状态渲染，不猜。
3. 报表响应必须带 `columns/rows/subtotal/totals/groups/truncated/dataAsOf/cache`；缺字段界面无法渲染小计与截断提示。
4. 错误码按 PRD 原样透出（`REPORT_*`），前端只做映射不吞码；400 的业务错误必须带可执行的修正建议字段或可推导字段（如 `groups`）。
5. 导出接口返回 `Content-Disposition` 文件名含报表名与时间；前端不自行拼文件名。
