## 0. 视觉与手感基线（look & feel，先读这节）

### 0.1 意图（一句话）

**安静的权限配置台**：管理员一眼看清"这个角色能进哪些页、能点哪些按钮"，每次勾选都有即时计数与可撤回的回应；它必须像一棵能扫读的树，而不是一张要横向滚动的巨表。

### 0.4 动效、加载与空态

- 只允许 `opacity` / `background` / `border-color` / `transform: translateY`。**禁止** scale、bounce、spring、粒子、渐变。
- 骨架：角色表 5 行 / 树 8 行 / 动作表 6 行（行高分别 48/32/52），**不用整页 spinner**；保存中用按钮内 loading，不遮罩页面。
- 空态必须区分（主操作不同）：
  - 无角色 → 「还没有自定义角色」+「新建角色」；
  - 树无页面 → 「没有可配置的页面」+「刷新」；
  - 筛选无结果 → 「没有匹配的页面或动作」+「清除搜索」；
  - 未选页面 → 右栏 compact：「从左侧选择一个页面」+ 一行「页面决定能不能进，动作决定能不能点」；
  - 仅看已授权且为空 → 「该角色还没有任何授权」+「关闭『仅看已授权』」。
- 错误：`ErrorState` 带 code/status + 重试；**409/400 一律不用 toast**，在保存条上方或对话框内联。
- `prefers-reduced-motion: reduce` → 过渡 ≤1ms，去位移。

### 0.6 几何自洽（1440 视口，写死，必须真的放得下）

- 1440 − 200（全局侧栏）− 40（AppShell 左右 padding）= **1200**；AdminLayout 子导航 160 + gap 16 ⇒ **正文 1024**。
  > 修订 r18 §0.6 的 1064：按 `web/src/layouts/AppShell.vue:102`（`padding:16px 20px`）与 `admin-shared.css:9`（160+16）实测为 **1024**，本版按 1024 排版。
- 授权页：左树 **320** + gap 12 + 右栏 **692**（内 16 ⇒ 内容 660）。
- 动作表四列：动作 **240**（min-width，超出 ellipsis）· 端点 **136** · 高危 **44** · 档位 **168**，列间距 3×12 ⇒ **624**，在 660 内留 36 余量。**1440 下端点列可见**；视口 <1440 时 `display:none`（媒体查询），端点改由动作码 `title` 承载——任何宽度都不出现横向滚动。
- 三档控件 164 宽落在 168 列内，文案「允许/受限/拒绝」各 2 字（26px）在 52 内不折行。
- 卡片高度：`height: calc(100vh - 288px); min-height: 480px`（288 = 48 顶栏 + 16 上 padding + 60 页头 + 12 + 36 工具行 + 12 + 56 保存条 + 12 + 36 下 padding）。1440×900 ⇒ **612**，树可见约 15 行、动作表约 10 行。
- 角色表 7 列：220 / 180 / 60 / 72 / 80 / 130 / 160 = **902**，在 992（1024−2×16）内。
- 高危/内置 pill 40 宽 = 2 字（22）+ 内边距 16 = 38 ≤ 40；「已停用」56 宽 = 3 字（33）+16 = 49 ≤ 56。
- 角色表单抽屉 640：左右内 24 ⇒ 592 单列；textarea 3 行 = 76，计数 `0·200`（12px）右对齐在其下 4px，容器高 100 不裁切。

### 0.7 反模式（本产品出现即返工）

- 渐变背景、大色块、彩色卡片、卡片阴影、圆角 >8、图标代替文字表状态。
- 树展开把动作也铺进左栏（36 页 × 72 动作会撑爆）；动作只允许出现在右栏。
- 三档用下拉框（每次要两次点击且看不到当前全貌）；三档用彩色实心块。
- 保存按钮置灰却允许编辑后无「未保存」提示；保存 1680 格无 loading。
- 每格单独 PUT、保存后整页 reload、保存后要求重新登录。
- 页面 DENY 但动作显示成"已生效"（必须黄警 + 不计入 effective）。
- 一屏两个主按钮；危险操作用主色。

## 3. 关键页线框

### 3.1 `/admin/roles` 角色列表

```
┌ 工具行  [搜索角色名/编码  ↵]   [仅看启用 ⚪]                    [ + 新建角色 ] ┐
├──────────────────────────────────────────────────────────────────────────────┤
│ 角色名           编码              类型  状态   用户数  更新时间      操作      │
│ 平台管理员       PLATFORM_ADMIN    内置  启用     3    11-12 10:20   授权 编辑  │
│ 产品经理         PMO               内置  启用    12    11-11 09:03   授权 编辑  │
│ 外部审计员       AUDITOR           —     已停用   0    11-12 14:02   授权 编辑 停用 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 列：角色名 220（14/500；描述有则第二行 12px 省略）· 编码 180（mono，ellipsis + title）· 类型 60 · 状态 72 · 用户数 80（右对齐，`title="该角色关联用户数"`）· 更新时间 130 · 操作 160。
- 行操作：`授权`（主色文字按钮，**唯一主操作**）· `编辑` · `停用/启用`（红色/常规，hover 才显示；内置角色停用 `disabled` + tooltip「内置角色不可停用，可改权限」）。
- 默认排序 `updatedAt desc`；搜索回车触发；「仅看启用」为 `el-switch` 尺寸 `small`；≤50 行不分页，>50 每页 20。
- 新建/编辑抽屉 640（`label-position="top"`）：
  - 角色名（必填 2–30，trim）；
  - 角色编码（必填 `^[a-z][a-z0-9_]{1,31}$`，mono；编辑态 disabled + hint「编码是审计与授权的稳定标识」）；
  - 描述（textarea 3 行，≤200，右下计数）；
  - 底部：取消 / 保存（定宽 96）。成功后：新建 → 关闭抽屉 + toast「已创建」+ 列表刷新并把新行滚入视口 + 行底色 `#EAF1FE` 渐隐 1.2s，并在该行提供「去授权」引导（toast 内文字按钮，3s）。
- 停用确认 480（`tone=danger`，必填原因，≤100）：
  - 正文两行：「该角色下 **N 名用户**将在下一次请求失去这些权限」「关联关系保留，重新启用即恢复」；若包含当前登录者追加红字「包括你自己，可能失去管理入口」；
  - 内置角色不弹（按钮已 disabled）。
- 错误：列表加载失败 → `ErrorState` + 重试；409 `ADMIN_LOCKOUT_RISK` → 对话框内联红字（不用 toast），文案含被拒码；400 校验 → 字段下方 12px 红字。

```
│ ▸ 我的              3/3     │                                            │
├─────────────────────────────┴────────────────────────────────────────────┤
│ 3 项未保存   [重置]                                    [ 保存并生效 ]  56px sticky │
└──────────────────────────────────────────────────────────────────────────┘
```

**默认态（决定"≤3 次点击"）**：进入页面即自动选中——优先「第一个有任一动作非 DENY 的页面」，否则「第一个模块的第一页」；树滚动到该项并高亮。因此从授权页点中任一动作档位 = **1 次点击**（列表点「授权」进入算第 1 次，总计 2 次）。

**左树（320，行高 32 / 模块行 36）**
- 模块行：tri-state checkbox + 模块名（13/500）+ `已授页/总页`（12，tabular-nums）；默认全展开，箭头 160ms。
- 页面行（缩进 16）：tri-state checkbox + 页面名 + 页面码（mono 11、`#86909C`，仅此处装饰用）+ 半选琥珀点 6px（`#C77700`，`title="N 个动作已授但页面未开放"`）。
- checkbox 与行点击**分离**：checkbox 有独立 `@click.stop`（勾选 = 批量改档，见 I1）；点行其余位置 = 选中并在右栏打开。
- 搜索：本地即时过滤（数据 ≤36 页）——命中页面保留其模块；命中动作时该页保留并显示「N 个动作命中」小字。
- 「仅看已授权」默认**关**：开启后隐藏「页面 DENY 且本页无任何动作非 DENY」的页面；整组全隐则藏组。

**右栏页头（高 60，下边 1px `#F2F3F5`）**
- 页面名 14/600 + 页面码 mono 12 + 页面准入三档控件（168 列内，标签「页面」）。
- 功能码 chips：每枚 = 功能码 mono 12 + 档位小字（允许绿/受限橙/拒绝红）；`title="该功能码被 N 个页面共用"`。
- 「高级」折叠区（默认收起；**若页面非 DENY 而任一绑定功能码为 DENY 则自动展开**）：逐项三档编辑，首行 12px 警示「改动会影响共用此功能码的 N 个页面」；`PLATFORM_ADMIN` 的 `org:manage`/`tenant:manage` 显示锁 + 禁改（AC-10）。

**动作表（行高 52，表头 sticky 40）**
- 列：动作 240（上行码 mono 12、下行中文名 13）/ 端点 136（mono 11、单行 ellipsis）/ 高危 44 / 档位 168。列宽见 §0.6，1440 无横向滚动。
- 工具行：`全选本页动作`（tri-state）+ `已授 x/y` + 右侧动作搜索（本地）。
- 高危行：中文名后「高危」pill；角色非 `PLATFORM_ADMIN` 且该动作将为非 DENY 时，保存走二次确认（I7）。
- 页面 DENY 但动作非 DENY：该行动作名后追加 11px `#9A5B00`「不生效」+ 页头警示条（I4）；行仍可编辑（保留配置）。
- 空态：本页无动作 → 「本页只有页面级准入，没有可单独配置的按钮」。

**保存条（sticky 56，跨两栏）**
- 左：`N 项未保存`（13/500）+ tooltip 摘要「页面 x / 动作 y / 功能码 z」；无改动 → 「无改动」+ 两个按钮 disabled。
- 右：`重置`（文字按钮，二次确认「放弃 N 项改动？」回到服务端快照）· `保存并生效`（主按钮，定宽 96，唯一主操作）。
- 保存中：按钮 loading、左文案「正在保存…」、控件不禁用；>2.5s 追加 12px「保存较慢，请勿离开」。
- 成功：toast「已保存 · 新增 a / 移除 b / 调整 c」（含高危追加「· 含 N 个高危」）2s；保存条归零；**总是**刷新 `/auth/me/permissions`（I6）。
- 失败：409 锁死 → 480 对话框「无法保存：会锁死管理员入口」+ 被拒码清单 + 「返回调整」（聚焦首个被锁控件）；400 未知码 → 保存条上方警示条 + 搜索框自动填入该码；网络错误 → 红条 + 「重试」。
- 离开拦截：有未保存改动时切路由/刷新 → 480 「有 N 项未保存」[留下] [放弃并离开]，并挂 `beforeunload`。

**角色态**：`status=DISABLED` 时页头加灰 pill「已停用」+ 顶部琥珀条「该角色已停用，其用户当前不获得任何授权；仍可继续配置」。

## 4. 交互规则（编号对 AC，dev 逐条实现）

- **I1 批量勾选语义**：模块 checkbox 勾选 = 该模块**所有页面**置 ALLOW（不动动作）；取消 = 全部 DENY。页面 checkbox 勾选 = 该页 ALLOW；取消 = DENY。`全选本页动作` 勾选 = 本页动作全 ALLOW；取消 = 全 DENY。批量操作**不覆盖**已显式设为 RESTRICTED 的项？——覆盖为 ALLOW（可再单独改回），因为 tri-state 的"半选 → 勾选"必须是确定结果。
- **I2 计数口径**：模块 `已授页/总页` 中"已授" = 页面 access ≠ DENY；右栏 `已授 x/y` 只统计动作 ≠ DENY；页头 `已授 14 页 · 38 动作` 按当前角色全量（不受搜索/过滤影响）。
- **I3 搜索与过滤**：搜索与「仅看已授权」叠加为 AND；搜索命中项父级自动展开；清除搜索恢复过滤前展开态。
- **I4 页面 DENY × 动作已授**：页头警示条 + 行动作「不生效」标记；`effective` 预览**不含**这些动作；保存仍成功且服务端回 `warnings`，toast 用警示样式 4s「已保存，有 1 项不生效」。**禁止**把这类动作计入"已生效"文案（PRD 反面目标 3）。
- **I5 三档切换**：单击选项即改（无需二次确认）；`aria-checked` 同步；键盘 ←→ 在组内移动并选中。改档只影响该 subject 一行。
- **I6 保存**：**1 次 PUT**（全量覆盖该角色 60+36+72=168 行，租户口径 1680 = 10 角色 × 168），单事务；成功后**始终**拉一次 `/auth/me/permissions`（不判断是否改到自己），若当前登录者菜单/动作集合变化，toast 追加一行「你的菜单已更新」；不 reload 页面、不要求重登。
- **I7 高危动作**：角色非 `PLATFORM_ADMIN` 且本次把 3 个高危动作任一从 DENY 改为非 DENY → 保存前弹 480 确认：列出动作码/名称/所属页 + 勾选「我了解该动作的影响」+ 主按钮「确认授予」；取消则不保存。服务端仍返回 `HIGH_RISK_REQUIRES_CONFIRM` 时按 TECHNICAL 的确认字段重放同一 PUT，前端不自行放行。
- **I8 防锁死**：`PLATFORM_ADMIN` 的 `org:manage`/`tenant:manage` 三档控件禁用 + 锁 + tooltip「平台管理员冻结码，不可移除」；服务端 409 `ADMIN_LOCKOUT_RISK` 覆盖前端（以服务端为准，库不变）。
- **I9 导航/按钮**：见 §3.4；`a3/a4` 断言以页面码双条件重写，**不得**只改常量。
- **I10 停用角色**：见 §3.1；停用/启用各写 1 条审计，成功后列表行状态就地更新（不整页刷新）。
- **I11 空角色（新建）**：初始全 DENY（0 行）；授权页打开时所有计数为 0/…，右栏默认选第一页，保存条「无改动」。不自动复制任何内置角色。

## 6. 可访问性（必做）

- **焦点**：全键盘可达；focus-visible 2px 主色环；树/表格用 roving tabindex。
- **树语义**：`role="tree"/"treeitem"`，`aria-level`、`aria-expanded`、`aria-checked`（半选用 `"mixed"`）；↑↓ 移动、→/← 展开折叠、Space 切 checkbox、Enter 选中页面。
- **三档**：`role="radiogroup"` + 3 个 `role="radio"`（`aria-checked`），`aria-label="<动作码> 档位"`；←→ 移动即选中。
- **保存条**：`role="status" aria-live="polite"` 播报「N 项未保存 / 正在保存 / 已保存」；toast `role="status"`，错误 `role="alert"`。
- **状态不只靠颜色**：停用/高危/不生效均有文字；状态 pill 文字色对比 ≥4.5:1（12px 辅助文字统一 `#6B7280`）。
- **禁用可读**：锁定的三档 `aria-disabled="true"` + 仍可聚焦，`aria-describedby` 指向原因文本。
- **缩放**：≥1280 两栏；1024–1279 树 280、隐藏端点列；<1024 单列（树折叠为顶部下拉）。200% 缩放下允许纵向滚动，**不接受**横向滚动。
- `prefers-reduced-motion` 生效（§0.4）。

## 7. 性能与渲染

- 只渲染当前选中页的动作表（≤10 行）与树的 36 页；模块折叠用 `v-show` 而非重建，首屏 DOM < 300 节点。
- 保存快照在点击瞬间深拷贝三档 map；保存中继续编辑不改变已提交快照（按钮文案提示）。
- 计数用 `computed` 一次遍历汇总，禁止在模板里 `filter().length` 逐行计算。
- 首屏骨架 ≤ 200ms 出现（本地数据，无网络时直接由 `modules[]` 渲染）。
