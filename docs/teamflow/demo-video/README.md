# 各角色流程演示视频（demo-roles.mp4）

**时长 1 分 54 秒 · 1440×900 · 30fps · 无配音，靠底部字幕条讲解 · 基线与 main `b7ab1ab`。**

这一版不是动画示意，也不是把 PPT 录屏——**画面全部来自真实运行中的平台**：演示数据由 `make platform-demo-reset` 重建，每一步状态流转都是打真实接口跑出来的（业务方提报 → 产品经理审批 → 入池 → 拆解 → 排期 → 指派厂商 → 开发 → 提测 → 测试通过 → 完成 → 关闭），截图时登录的是对应用户，看的是他自己的视角。

## 重录方式

```bash
make platform-up && make platform-demo-reset   # 干净演示数据
# 1) 用 CDP 驱动真实操作 & 截图（脚本思路见 docs/teamflow/DEMO-BY-ROLE.md §7.4）
#    截图落在 /tmp/video/frames/
node docs/teamflow/demo-video/render.mjs       # 2) 按 captions.json 生成带字幕的帧
ffmpeg -y -f concat -safe 0 -i /tmp/video/list.txt -vf "fps=30,format=yuv420p" \
  -c:v libx264 -preset medium -crf 23 -movflags +faststart demo-roles.mp4   # 3) 合成
```

`captions.json` 是全部文案与时长（改文案只改这里，不放字幕进图片）。`slide.html` 是字幕条模板（1440×900，底部渐变条 + 三段文字）。

- 无配音、无鼠标轨迹高亮（截图式演示，不是录屏）
