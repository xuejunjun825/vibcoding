# UI 风格基线（参考：嘉为蓝鲸 DevOps 界面截图）

> 用户提供「蓝鲸 DevOps」版本管理页面截图作为**界面风格参考**（m00589 图片）。本文件把截图里的视觉语言固化为可实现的设计令牌与页面骨架，前端一律照此实现；与 PRD 冲突时以 PRD 功能为准、本文件管样式。
>
> 技术落点：Vue 3 + Element Plus，通过覆盖 Element Plus CSS 变量（`--el-color-primary`、`--el-border-radius-base` 等）+ 一层自研主题样式实现，不引入第三方 UI 框架、不做暗色主题（一期）。

## 1. 风格定位

**企业级 B 端、安静克制、信息密度中高。** 参照对象的观感：白色卡片 + 极浅灰底、1px 细边框、几乎无阴影（仅浮层有）、蓝色只用于「主操作 / 当前项 / 链接 / 数据强调」，状态用低饱和浅底彩色 pill 表达。**不要**：渐变、大色块、重阴影、大圆角、插画、花哨图标。

## 2. 骨架（三区布局，全平台统一）

```
┌──────────┬──────────────────────────────────────────────────────┐
│ 全局侧栏 │ 顶部业务导航（需求 任务 缺陷 看板 迭代 版本 报表 设置）  │
│ 200px    ├──────────────────────────────────────────────────────┤
│ logo     │ 页面标题行 + 主操作按钮（右上或标题右侧）              │
│ 工作区切换├───────────────┬──────────────────────────────────────┤
│ 分组菜单 │ 左列表 320px   │ 右详情（tab + 内容区 / 浮层详情卡）    │
│ ...      │ （卡片或表格）  │                                      │
│ 底部帮助 │               │                                      │
│ 消息/用户│               │                                      │
└──────────┴───────────────┴──────────────────────────────────────┘
```

- **全局侧栏**：宽 200px、白底、右 1px 边框；顶部 logo（图形 + 产品名）、工作区切换器（带下拉）；菜单按业务分组（需求域/交付域/分析域/设置），条目高 40px、16px 线性图标 + 13px 文字；当前项浅蓝底 + 主色文字 + 左侧无粗条。底部固定：帮助中心、消息通知（红点数字角标）、用户（头像 + 昵称 + 菜单）。
- **顶部业务导航**：高 48px，白底，1px 底边框；条目 14px、间距 24–28px；**当前项 = 主色文字 + 2px 主色下划线**（不做胶囊底）。
- **页面标题行**：左「标题 + 状态/计数」，右主操作（主按钮）+ 次级操作（图标按钮/更多 ▾）。
- **双栏内容**：左列表（320px，卡片式条目或紧凑表格），右详情（tab 导航 + 内容），中间 1px 分割；详情里的轻量信息用 **popover 详情卡**（如截图的「版本详情」浮层），重内容才用抽屉/整页。
- 左侧列表当前项：浅蓝底（`--bg-selected`）+ 1px 边框，不加大色块。

## 4. 字体与字号

系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`；数字用等宽感（`font-variant-numeric: tabular-nums`）保证看板对齐。

| 场景 | 字号/字重 |
| --- | --- |
| 页面标题 | 16px / 600 |
| 区块标题、卡片标题 | 14px / 500–600 |
| 正文、表格内容、按钮 | 13px / 400（按钮 500） |
| 列头、辅助信息、时间戳 | 12px / 400（次要色） |
| 大数字（看板卡片） | 24–28px / 600 |

## 5. 组件规范

- **按钮**：主按钮=主色实心白字、高 32px、圆角 6px；次按钮=白底 + 边框；文字按钮=主色无底；危险操作=红字或红边；一屏最多 1 个主按钮。
- **状态 pill**：浅底 + 同色文字 + 6px 圆角（**不是**胶囊）；「未开始」橙、「进行中」蓝、「已完成」绿、「Backlog/已关闭」灰；表格内 pill 高 20–22px、字号 12px。
- **优先级**：彩色圆点 + 文字（P0 红 / P1 橙 / P2 蓝 / P3 灰），不用色块。
- **表格**：行高 44–48px；表头浅灰底、12px 次要色、可排序列带上下箭头；首列可带星标（收藏）与行图标；最后一列 `⚙` 列设置；hover 行浅灰底；行操作**默认隐藏，hover 显示**（编辑/复制/更多 ▾）。
- **筛选条**：与表格同区，左侧「筛选 ▾ + 排序箭头 + 视图切换（表格/卡片）」，右侧搜索框（回车触发）+ 展开图标；状态计数用「全部 4 / 未开始 3 / 进行中 0 / 已完成 1」的行内胶囊计数。
- **tab**：文字 tab + 2px 主色下划线（与顶部导航一致），tab 数量 ≤ 8。
- **进度**：细进度条（高 6px、圆角、主色/成功色）+ 右侧百分比数字；卡片里的进度显示为「1 / 4」。
- **浮层详情卡（popover）**：白底、8px 圆角、轻阴影；两列表格（字段名/值），值域超长换行，不在浮层里放操作按钮（操作回详情页）。
- **空状态**：灰底图标 + 一句说明 + 主操作按钮；**不用**插画。
- **表单**：标签右对齐或上下堆叠二选一（同一页面统一），必填星号红色；校验错误在字段下方 12px 红色文字。
- **反馈**：操作成功用轻量 toast（右上，2s），破坏性操作二次确认（弹窗写明影响范围），长任务（导出/导入）走异步任务提示 + 完成 toast。

## 6. 页面模板（映射到 PRD 功能）

| 页面 | 用哪个模板 | 关键元素 |
| --- | --- | --- |
| 需求池（§4.3） | 双栏列表页 | 左：需求卡片列表（类型 tab、状态 pill、父需求、人天）；右：详情 tab（工作项/概览/关联信息/需求日志/测试计划） |
| 版本计划（§4.6） | 双栏卡片列表（截图同款） | 左：版本卡片（名称、状态、起止日期、需求进度 x/y、更多）；右：概况 + 版本详情浮层 + 版本内工作项表 |
| 迭代看板（§4.15） | 看板页 | 状态列 + 人泳道，卡片可拖，列头计数 |
| 缺陷（§4.14） | 双栏列表页 | 同需求池，严重级用圆点、状态用 pill |
| 发布上线单（§4.16） | 详情表单页 | 准入校验清单（逐项 PASS/FAIL 图标 + 说明）置顶，失败项不折叠 |
| 工作台（§4.9） | 仪表盘网格 | 顶部待办条 + 快捷动作 + 数据卡片（数字+环比）+ 我的列表；卡片 8px 圆角、白底、无阴影 |
| 看板/报表（§4.10/§4.11） | 仪表盘 + 拖拽区 | 指标卡统一数字样式；图表配色用主色系单色阶 + 语义色 |
| 审批中心（§4.8） | 左列表 + 右单据详情 | 右栏固定「同意/驳回/转办/加签 ▾/减签」操作条 |
| 用例库（§4.20） | 左模块树 + 右用例表 | 树+表格双栏；用例详情用右侧抽屉（步骤可编辑、版本切换） |
| 测试计划与执行（§4.20） | 表格 + 执行面板 | 执行结果用 pill（通过绿/失败红/阻塞橙/跳过灰）；失败行「转缺陷」按钮在 hover 显示 |
| Wiki（§4.21） | 左页面树 + 右正文 | 正文最大宽度 900px；顶部「编辑/历史/收藏」；版本对比左右分栏、差异高亮 |
| 甘特图（§4.22） | 全宽时间轴页 | 左侧列表 320px 固定 + 右侧时间轴横向滚动；今天竖线主色细线；超期条变橙 |
| 价值流看板（§4.23） | 仪表盘 + 阶段条 | 阶段用横向箭头条（阶段名/WIP/停留时长）；点击阶段下钻列表 |
| 租户管理（§4.24） | 表格页 | 隔离形态用 pill（ROW 灰 / SCHEMA 蓝 / DATABASE 紫）；迁移操作二次确认 + 进度条 |

## 7. 交互约定

1. 当前项高亮用「浅蓝底 + 主色文字」，不用粗色条；滚动区独立（左列表、右详情各自滚动）。
2. 列表默认按「更新时间倒序」，筛选条件在 URL/查询参数可复现，刷新不丢。
3. 搜索回车触发，不做输入即搜（大数据量）。
4. 表格列可显示/隐藏并记忆（用户级偏好），排序仅后端排序。
5. 危险操作（删除版本、强制放行、减签、关闭迭代）必须二次确认 + 填原因（如适用）。
6. 所有异步动作有 loading 态，禁止无反馈等待；接口失败给可读错误 + 重试入口。
7. 权限不足：按钮不渲染（而不是点了报错）；越权访问 403 页面给「返回首页」。

## 8. 反例（出现即返工）

- 使用渐变背景、大面积品牌色块、彩色卡片。
- 主按钮一屏超过 1 个；按钮颜色与语义不符（危险操作用蓝）。
- 表格状态用纯文字+颜色区分（必须 pill + 文字，色弱可辨）。
- 详情用全屏抽屉承载轻量字段（应先用 popover）。
- 为强调而在卡片上加阴影 / 边框加粗 / 圆角 > 8px。
